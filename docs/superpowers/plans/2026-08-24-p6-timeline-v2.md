- bookmark/summary_manager 决策与桥事件、hmd/probe 本地化、incoming-letter 桥分别属 P4/P7/P1/P5，不在本计划内（spec P6 验收仅要求 run 脚本级验证）。

- mod 侧：替换 checkpoint effects（8→363 行）、三个 log_gamedata init 行**删除 totalDays 字段并追加协议尾部字段**（双侧 schema 对齐，见"已验证事实基线"）、战报/信件路径补 prepare/bump/snapshot；对话关闭的 bump 由 app 端 run 文件驱动（与 1.x 相同），mod 侧无需额外对话事件改动。

```powershell
  $bytes = [System.IO.File]::ReadAllBytes((Resolve-Path $f))
  $hex = ($bytes[0..2] | ForEach-Object { $_.ToString('X2') }) -join ' '
  "{0} : {1}" -f $f, $hex
}
```
